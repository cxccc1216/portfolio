拼多多投流推广实战手册

这是三份文档里最该反复看的一份。
涉及具体金额、比例的地方，我给的是参考区间，你要用自己的类目数据去校准。平台推广产品的名字和门槛变化很快，文中按功能分类讲，你后台叫什么名字不重要，对得上逻辑就行。

0. 先把一件事想明白：投流到底在买什么

投流买的是曝光，不是销量。

平台收你的钱，给的是"让更多人看到你的商品"。至于看到之后买不买，取决于你的主图和价格。所以：

图不行、价不行，投流就是把钱扔进水里。

这句话的实践含义是：推广出问题的时候，第一反应不应该是"调出价"，而是"看图和价"。 新手 80% 的推广亏损，根子都在图和价，不在出价技巧。

核心公式（整个手册都围绕它）

ROI = 成交金额 ÷ 推广花费
    = (曝光量 × 点击率 × 转化率 × 客单价) ÷ 推广花费

这个式子的左侧是你考核的指标，右侧是你能动手的四个变量：

变量 谁来管 优化手段
曝光量 出价、预算、定向 加价、放宽人群、加预算
点击率 CTR 主图、价格、标题 改图、改价
转化率 CVR 详情页、评价、价格、服务 改详情、积累评价、调价
客单价 SKU 结构、搭配、满减 加套装、设满减

记牢这张表。 后面所有诊断，最后都会落到"这四个变量里，哪个出问题了"。

1. 推广工具的三大类型（按功能分类）

不管你后台看到的按钮叫什么，推广工具就三种逻辑。

1.1 搜索型——"人找货"

原理：顾客搜关键词，你竞价买关键词下的展示位。

特点：

  • 流量精准，因为顾客已经明确想买这个东西
  • 可控性强，你能精确知道你为哪个词花了多少钱
  • 量级有限，受这个词的搜索量天花板限制
  • 转化率通常最高，但点击成本也高

适合：有明确搜索需求的品（日用品、配件、有确定型号的标品）、新店起步、有精准长尾词的类目。

新手建议从这里开始，因为它最可控，数据最好读，能帮你快速搞清楚"我的图和价到底行不行"。

要盯的数据：每个关键词的曝光量、点击率、点击成本、转化率、花费产出比。

核心动作：加词、删词、调词价。

  • 有曝光没点击 → 图的问题，或者词不精准
  • 有点击没转化 → 价的问题，或者详情页/评价的问题
  • 有转化但产出低于目标 → 降这个词的出价，或者提高客单
  • 花钱多不出单的词 → 直接删

1.2 推荐型／信息流——"货找人"

原理：系统根据人群标签，把你的商品推给可能感兴趣的人，出现在信息流、猜你喜欢等位置。

特点：

  • 量大，天花板比搜索高得多
  • 点击成本通常低
  • 精准度差，转化率通常低于搜索
  • 对主图的视觉冲击力要求极高，因为顾客是"被吸引"而不是"主动找"

适合：视觉冲击强的品（有设计感、有对比效果、能一眼看出用途）、冲动消费品、客单价中等偏低的品。

要盯的数据：人群包的点击率和转化率、不同场景位的表现差异。

核心动作：调人群、调场景、换图。

  • 某个年龄段/人群包花钱不出单 → 屏蔽或降价
  • 某个展示位数据特别好 → 加大投放
  • 整体点击率低 → 换图，不是调价

1.3 智能托管型——"系统帮你花"

原理：你设一个目标产出比（或类似目标），系统自动出价、自动分配流量。

特点：

  • 省心，不用天天盯
  • 适合已经跑通、数据稳定的款
  • 黑盒，你很难知道钱具体花在哪里
  • 冷启动期不好用，因为系统没有你的数据，它不知道该找谁

适合：已经验证过的爆款放量、没时间天天盯计划的阶段。

注意：智能托管是"放大器"，不是"起搏器"。没有数据积累的款，别交给它。

1.4 三种工具的配合逻辑

新店起步期：搜索型为主（搞清数据和转化），推荐型小预算测试（试图）

跑通之后：搜索型稳住基本盘，推荐型放量拉大盘

稳定期：智能托管解放精力，人工盯头部计划

大促／活动期：三种一起上，冲排名

2. 起量四步法（核心操作流程）

这是全篇最重要的一章。 顺序不能乱，跳步骤一定亏钱。

第一步：测图（3—5 天，极低预算）

目的：找到点击率最高的主图。这是投流里性价比最高的一件事。

为什么必须先测图：同样的曝光，CTR 从 1% 提到 2%，你的流量直接翻倍，成本不变。这是唯一能"免费"提升效果的操作。

怎么测：

  1. 准备 2—4 张差异明显的主图（不是微调字色，是整体构图和卖点表达不同）
  2. 用搜索型工具开一个小预算计划，或者用同一商品建多个推广单元，各挂一张图
  3. 预算压到最低，跑到每张图都有几百次曝光

判断标准：

  • 有差异显著的那张最好 → 换上去
  • 数据差不多 → 说明图都没抓住点，回去重新想卖点，别将就
  • 看点击率，不看转化率（这个阶段样本太小，转化数据不可信）

关键纪律：测图期间不要改价、不要改标题、不要改详情页。 同时改多个变量，你就不知道是哪个起了作用。

第二步：测款（3—7 天）

目的：判断这个款值不值得投入。

怎么测：用最低预算跑，重点看三个数：

  1. 加购率和收藏率——有兴趣但还没决定，是转化的前置信号
  2. 转化率——横向和你的其他款比，和自己类目的整体水平比
  3. 退款率——这个最容易被忽略，但决定了你长期赚不赚钱

判断标准（参考，必须用自己类目校准）：

  • 转化率明显高于店内其他款 → 主推
  • 转化率一般但加购率高 → 可能是价格问题，试着调价再看
  • 退款率异常高（显著高于同行）→ 别推了，先解决产品问题。推广一个高退货率的款，等于花钱买退货

这里的判断逻辑要清楚：测款不是为了"证明我的款好"，是为了"淘汰掉不行的款"。敢于砍款，是新手到老手的分水岭。

第三步：放量（跑通之后）

怎么放：

  • 预算递增用"爬楼梯"，不要"跳楼"：每 2—3 天涨 20%—50%，观察产出比有没有守住
  • 不要一次翻倍：预算突然翻倍，系统会把你推到更宽泛的人群，转化率必然下降
  • 加到产出比开始明显下滑，就退回上一档，停在那里

放量时最容易犯的错：产出比一好就加大预算，结果崩了，然后慌，然后降价，然后全乱。记住：加预算必然带来效率下降，这是正常的。问题是下降到什么程度你能接受。

纪律：提前写下你的"目标产出比底线"，跌破了就退回上一档。不要在情绪里做决策。

第四步：优化（长期持续）

优化的顺序永远是：先看哪一段出问题，再动手。

曝光不够 → 加价 / 放宽定向 / 加预算
点击不够 → 改图（几乎永远是图的问题）
转化不够 → 改价 / 补评价 / 改详情页
客单不够 → 加套装 / 设满减 / 调 SKU 结构

每次只动一个变量，动完等 3 天。 这条纪律能帮你省下大量冤枉钱。

3. 出价与预算的实操规则

3.1 冷启动期（前 3—7 天）

目标不是赚钱，是拿到数据。

  • 出价可以比你的目标成本略高一点，目的是先让计划跑起来。跑不起来的计划，你连诊断的机会都没有
  • 预算设小，宁可跑完再加，也不要一次给大
  • 别关计划关得太快。新计划有学习期，第一天数据差是正常的，至少给它 2—3 天

新手最常见的错误：开计划 → 两小时没出单 → 关掉 → 再开一个新计划 → 循环。这是最烧钱的做法，因为每次都在给系统交"学习成本"，从来没有积累。

3.2 稳定期

  • 逐步把出价往下压，压到产出比刚好在目标线上
  • 一天调整不超过 2 次，每次幅度别太大
  • 转化稳定的计划不要乱动。手痒是运营最大的敌人——数据好的时候动作越少越好

3.3 什么时候该加价

  • 曝光明显不足，且图和数据都验证过没问题
  • 有转化，但流量上不去，明显被出价卡住了
  • 大促或活动窗口期，需要抢量

3.4 什么时候该降价

  • 花费一直在涨，产出没跟上
  • 某个词的点击成本高得离谱，但转化一般
  • 目标是保利润，不是冲量

3.5 什么时候必须停（红线）

  • 连续 3 天产出比远低于目标，且改图调价都没效果 → 停，回去重新看产品和定价
  • 退款率异常高 → 停，产品问题不解决，推得越多亏得越多
  • 库存不足 → 停，别推广一个发不出货的商品（会被罚）
  • 数据完全没起色（曝光都跑不出去） → 停，重新检查商品本身有没有问题（是否被限流、类目是否放错）

4. 人群与定向

4.1 基本逻辑

系统给你的人群包，本质上是按"行为 + 属性"划分的。你要做的是用钱去投票：哪个包出单多，就给它更多预算。

4.2 实操方法

  1. 先宽后窄：一开始不要设太细的限制，让系统自己找。跑出数据后，再把不出单的人群屏蔽掉
  2. 看"点击率"和"转化率"两个数：
    - 点击率高、转化率低 → 人是对的，但你的商品没说服他（图或价的问题）
    - 点击率低、转化率高 → 人对、图不行，或者这个人本来就想买（值得加价）
    - 两个都低 → 这个人群直接砍掉
  3. 老客人群：复购型产品要单独做老客定向，成本比拉新低很多
  4. 竞品人群：平台一般会有类似"竞品访客"的定向，这类人群购买意图明确，值得试

4.3 一个反直觉的建议

别迷信"精准人群"。 新店最大的问题是量不够，太精准意味着量小、跑不动、数据样本不足、没法优化。新店的第一阶段，宁可要"粗糙但量大"的流量，也不要"精准但跑不动"的流量。 量跑起来之后，再逐步收窄。

6. ROI 提升的三条路径（数学拆解）

从公式看，提升产出比只有三条路。每条路的具体动作不一样，先判断自己该走哪条。

路径一：提高点击率（最便宜的一条路）

为什么最便宜：改图的成本几乎为零，效果立竿见影。

具体动作：

  • 第 1 张主图只讲一个最强卖点，不要堆
  • 加对比（前后对比、用法对比、"别人家 VS 我们家"）
  • 用明确的数字和结果（"能用 3 年""一次搞定"），但不能虚假宣传
  • 换个角度看：如果同行都在摆拍，你用真实使用场景，反而更抓眼
  • 测图，测图，测图。这是唯一能客观判断的方法

判断标准：改完之后 CTR 有没有明显上升。没有上升就说明改错了方向，继续试下一个。

路径二：提高转化率

具体动作（按性价比排序）：

  1. 补评价（最有效）：新链接 5—10 个真实好评，转化率能有质的提升
  2. 调价：对比前 3 名竞品，如果贵了就降，如果一样就要靠别的东西取胜
  3. 改详情页：把顾客最常问的三个问题，直接在详情页回答掉
  4. 强化服务承诺：比如清晰写清退换规则、发货时效
  5. 优化规格说明：减少"买错规格"导致的退货

注意：转化率是最难提的一项，因为它是产品力的直接体现。如果试完这些还是不转化，问题可能在这个产品本身，不在运营技巧。

路径三：提高客单价

这是被最多人忽略的一条路。

同样的流量，同样的推广花费，客单价从 30 提到 45，产出比直接提升 50%，而且不额外花一分推广费。

具体动作：

  • 加套装：单件 → 两件装 → 家庭装。套装的价值是让顾客觉得"更划算"
  • 设满减/满赠：把门槛设在略高于平均客单价的位置，比如平均客单 40，门槛设 59
  • SKU 引导：把利润款的 SKU 放在中间位置，配图和名称做得更有吸引力
  • 搭售关联商品：配件、耗材、替换装——复购型耗材是最好的搭售品
  • 多件优惠：第二件半价这类机制

判断标准：加客单的动作不要影响转化率。如果加了套装反而没人买了，说明门槛设太高或者组合不吸引人。

7. 分场景打法

7.1 新店破零期（0—2 周）

  • 目标：跑出数据，找到能推的款
  • 预算：最低档，宁可少不可多
  • 重点工具：搜索型为主
  • 关键动作：先补评价，再测图，再测款
  • 心态：这个阶段花的钱是"学费"，不要指望产出比好看

7.2 稳定放量期（2 周—2 个月）

  • 目标：把跑通的款放大
  • 预算：逐步爬楼梯
  • 重点工具：搜索型稳盘 + 推荐型拉量
  • 关键动作：每个款单独设目标产出比，跌破就退档
  • 注意：这个阶段最容易因为贪婪而崩盘。加预算的节奏一定要慢。

7.3 活动冲刺期

  • 目标：抢排名、拿活动流量
  • 预算：临时提高，但要提前锁定上限
  • 关键动作：活动前 2—3 天开始加预算养计划，活动期间全开
  • 注意：活动期间的亏损要在预算里提前预留，不要活动完了才发现亏了

7.4 清库存期

  • 目标：回笼资金，不为利润
  • 打法：低价 + 推荐型流量，不投搜索型的贵词
  • 注意：清库存不要把店铺主力款的价格带打乱。最好用独立的链接去清，不要用主链接降价。

7.5 遇到竞品价格战

  • 别第一时间跟着降。先判断对方是不是在清库存或者短期活动
  • 如果不能不打，用赠品、加量、套装做价值对比，比直接降价的伤害小
  • 记住了：你能打的价格战，对方也能打；打到最后的赢家是成本最低的那个，不是你

8. 每日推广检视清单（照着念一遍）

每天 10 分钟，回答这 6 个问题：

  • [ ] 昨天花了多少钱？出了多少单？产出比是多少？在目标线以上吗？
  • [ ] 有没有哪个计划的花费突然涨了或者掉了？（异常比绝对值更重要）
  • [ ] 有没有哪个计划连续 3 天低于目标产出比？（该处理了）
  • [ ] 有没有哪个词/人群一直在花钱但不出单？（该砍了）
  • [ ] 我昨天改了什么东西？改完的数据有没有变化？
  • [ ] 今天有没有什么该做的动作（补评价、改图、报活动）？

如果这 6 个问题里有 3 个回答不上来，说明你的数据看板没搭好。 先把看数据的习惯建立起来，比学任何技巧都重要。

9. 最后：关于投流的三条底层认知

第一，投流是放大镜，不是发动机。
它能放大你已有的转化能力，不能创造转化能力。转化率 1% 的链接，投再多钱还是 1%。

第二，先算账，再投钱。
投之前先算清楚：我的成本是多少、目标产出比是多少、按这个产出比我能承受多大的预算。没算账就投钱，等于闭着眼开车。

第三，快钱来得快，去得也快。
平台流量有波动是常态。能活下来的店，都是靠产品和服务，不是靠某个投流技巧。 技巧只是让你少交学费，不改变生意的本质。
